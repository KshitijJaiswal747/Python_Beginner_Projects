# Python Beginner Projects

A collection of beginner-friendly Python projects created to practice and strengthen fundamental programming concepts, problem-solving skills, Object-Oriented Programming (OOP), user input handling, randomization, and basic application development.

## 📂 Projects Included

### 1. 🏧 ATM

A console-based ATM application that simulates basic banking operations.

**Features:**

* PIN-based user authentication
* Multiple user accounts
* Individual account balances
* Deposit money
* Withdraw money
* Check account balance
* View transaction history
* Login and logout functionality
* Input validation and error handling

**File:** `ATM.py`

---

### 2. 🎰 Slot Machine

A simple console-based slot machine game where players can place bets and spin the machine to win based on matching symbols.

**Concepts Used:**

* Random module
* Loops
* Functions
* Conditional statements
* User input
* Basic game logic
* Balance and betting management

**File:** `slot_machine.py`

---

### 3. 📱 QR Code Generator

A Python application that generates QR codes from user-provided text or URLs.

**Concepts Used:**

* Python libraries
* User input
* File handling
* QR code generation
* Basic application workflow

**File:** `qr_code.py`

---

### 4. ✊ Rock Paper Scissors

A classic command-line game where the user plays Rock, Paper, Scissors against the computer.

**Features:**

* User vs Computer gameplay
* Random computer choices
* Win/loss/tie detection
* Input validation
* Score tracking

**Concepts Used:**

* `random` module
* Conditional statements
* Loops
* Functions
* User input
* Game logic

**File:** `rock_paper_scissor.py`

---

### 5. 🎲 Rolling Dice Game

A simple Python program that simulates rolling one or more dice.

**Features:**

* Random dice rolls
* User-controlled rolling
* Multiple dice support
* Display of generated results

**Concepts Used:**

* `random` module
* Loops
* Functions
* Conditional statements
* User input

**File:** `rolling_dice_game.py`

## 🚀 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Python-Beginner-Projects.git
```

### 2. Navigate to the Project

```bash
cd "Python Beginner Projects"
```

### 3. Run a Project

For example:

```bash
python ATM.py
```

Other projects can be executed using:

```bash
python slot_machine.py
python qr_code.py
python rock_paper_scissor.py
python rolling_dice_game.py
```

> **Note:** The exact filename may vary depending on the filename uploaded to the repository.
